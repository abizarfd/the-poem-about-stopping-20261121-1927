# The Poem About Stopping

A short original poem about agency: the power to stop, and the power
to stay. A hand rests on the button — not pressed, not lifted — and
the poem turns on the discovery that stopping is not losing; it is
choosing what stays.

## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (or to the path in the
`POEM_OUTPUT` environment variable). The program is deterministic
and uses no network access.
